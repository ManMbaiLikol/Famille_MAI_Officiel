# 🌳 Site Web Famille MAÏ

Site web généalogique interactif de la Famille MAÏ, descendants de la lignée ancestrale des MA GWAHÈ du village MINSE (pays Bassa, Cameroun).

## 📋 Description

Ce site préserve et célèbre l'histoire de la Famille MAÏ, de l'ancêtre fondateur **LÔGA** jusqu'aux générations actuelles. Il offre une expérience interactive pour explorer plus de **5 générations** et **150+ membres** de la famille.

## ✨ Fonctionnalités

### Pages principales
- **🏠 Accueil** : Présentation générale de la famille avec statistiques
- **📜 Histoire & Origine** : Récit complet de MANGWAHÈ, de NGO NEMB et de la lignée MAÏ
- **🌳 Arbre Généalogique** : Vue cascade interactive avec recherche et filtres
- **📞 Contact** : Informations de contact de la famille

### Arbre Généalogique Interactif
- ✅ Vue en cascade élégante avec 5 générations
- ✅ Recherche en temps réel par nom
- ✅ Filtres par branche (BENA LÔGA, DJAP LÔGA, etc.)
- ✅ Filtres par génération
- ✅ Filtres par statut (vivants/décédés)
- ✅ Cartes interactives avec informations détaillées
- ✅ Identification visuelle (couleurs homme/femme)
- ✅ Navigation fluide et responsive

## 🎨 Design

- **Palette de couleurs** : Vert (#004d40, #00695c, #6c8b63) et Or (#d2a94d, #f4d03f)
- **Typographie** : Playfair Display (titres) + Lato (corps de texte)
- **Responsive** : Compatible desktop, tablette et mobile
- **Animations** : Transitions fluides et effets hover élégants

## 🚀 Technologies utilisées

- HTML5
- CSS3 (Grid, Flexbox, Animations)
- JavaScript Vanilla
- Design responsive sans framework

## 📱 Installation et utilisation

### Méthode 1 : Hébergement local avec WAMP/XAMPP/MAMP

1. Clonez le dépôt dans votre dossier `www` ou `htdocs`
```bash
git clone https://github.com/[votre-username]/Famille_MAI_Officiel.git
```

2. Ouvrez votre navigateur et accédez à :
```
http://localhost/Famille_MAI_Officiel/
```

### Méthode 2 : Ouverture directe

Ouvrez simplement le fichier `index.html` dans votre navigateur.

### Méthode 3 : Hébergement web

Uploadez tous les fichiers sur votre serveur web et accédez via votre nom de domaine.

## 👨‍👩‍👧‍👦 À propos de la Famille MAÏ

La Famille MAÏ trouve ses racines dans le village **MINSE** (MANGWAHÈ), au cœur du pays Bassa au Cameroun. Notre histoire remonte à plus de **200 ans**, commençant avec l'ancêtre fondateur **LÔGA** et ses quatre fils qui ont établi les grandes familles fondatrices.

### Les quatre familles fondatrices
- LOG LÔGA
- LOG DJAB
- LOG BILIM
- LOG HOL

### Valeurs cardinales
- 🪶 **Unité** : Nous venons d'une même racine
- 🌾 **Mémoire** : Nos ancêtres vivent à travers nos récits
- 🌍 **Dignité** : Porter le nom MAÏ, c'est marcher droit, avec honneur
